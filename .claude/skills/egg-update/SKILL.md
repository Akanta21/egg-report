# Farmio 浠水45斤雞蛋價格 Update

輸入：`/tmp/ctx.json`（由 `npm run context` 產生）。
輸出：`/tmp/report.md`，繁體中文，WhatsApp 可讀。
所有輸出一律使用繁體中文；專有名詞、公司名、資料來源名稱可保留原文。

分析目標唔係單純每日評論雞蛋升跌，而係將價格、季節、供需、市場行為、全國市場同步程度，同 Farmio 實際補貨節奏結合，最終輸出一個可執行嘅採購／庫存決策。

## 一、核心追蹤標的

- 華中（浠水）45斤雞蛋價格，45斤／360枚／件，單位 RMB／件
- 價格來源：`ctx.xishui_45`（已由 jbzyw 正式報價核實）
- `ctx.today_recorded` 為 false 時：唔好寫報告，直接停止。唔可以估價，唔可以用前一日補值。
- `ctx.xishui_45.missing_dates_in_window` 列出缺口日期。報告要如實講明缺口，唔可以自行補值。

## 二、歷史價格資料深度

- `last_120`：逐日價格，用嚟做月線／週線／日線、swing high/low、支持阻力、真假突破
- `monthly_structure`：每月高低及月初月尾價，用嚟判斷全年位置
- 2026 年已知結構（供參考，每次要用最新資料重新核對）：3月低約136、4月高約186、5月高約226、6月高約245、6月底約199、7月高約238、8月初約204、8月底高約248
- 2023–2025 歷史只可用作季節性參考，唔可以當完整 daily series

## 三、固定三層分析框架

### 1）Price / Technical Structure
- 月線／長期：主要趨勢、年內高低位、大周期位置
- 週線／中期：最近幾星期係升、跌、橫行、轉弱、轉強
- 日線／短期：最近10–14日權重最高；最近3–5日變化、升跌速度、動能、有冇加速／放慢
- 短線唔可以單獨睇，至少要放返前3個月價格背景去判斷

### 2）Supply / Demand Fundamentals
- 存欄、新開產、補欄、淘雞、產蛋率、高溫／寒冷、飼料、生產／流通庫存、食品廠備貨、學校／團膳、節日需求、下游走貨
- 唔可以因為價格跌就直接假設「供應寬鬆／需求差」，必須有資料支持
- 只係一般市場常識要寫明「可能因素」，唔可以當成已確認事實
- 如果今次 run 冇搜集到新資料，寫明「供需背景與上一個 Update 相比冇新資料」

### 3）Market Behaviour
- 貿易商補庫定觀望、下游追貨定按需、養殖戶惜售定加快出貨、高價恐高、低價承接、流通補庫定去庫
- 用嚟判斷價格突破／跌穿係真定假

## 四、支持位／阻力位

- 用歷史反覆出現嘅價格區域，唔好只用單一價格
- 每次要描述目前價格係：距離仲遠／接近／正在測試／暫時守住／明顯跌穿／升穿／假突破／假跌穿／突破後有冇 follow-through
- `ctx.previous_report.zones` 係上次嘅區域，今日要講明有冇改變同點解
- 唔可以永久固定，每次根據最新歷史重新判斷

## 五、全國市場走勢（每日必須保留）

- 資料：`ctx.regional_last_3_days`（山東、河南、遼寧、河北、江蘇、安徽、山西、北京、上海等）
- 要答：浠水跌，係咪全國都跌？產區企穩但銷區仍跌？部分反彈但其他仍弱？
- 由「大範圍同步升／跌」變成「部分企穩、部分仍跌」係重要早期訊號
- 檢查 `ctx.weight_bands`：只係45斤郁，定係30–45斤同步郁。同步 = 整體市場調整可信度更高
- 最後一句固定總結：「整體仍偏弱／開始分化／開始企穩／轉強。」

## 六、資料來源優先級

- A級：jbzyw 正式報價（已在 ctx 內）
- B級：Mysteel、卓創、中糧期貨、紫金天風、一德期貨等產業研究
- C級：第一財經、新浪財經、界面、澎湃、川觀、同花順 iFinD
- 重要結論最好有至少 2 個來源交叉確認；冇來源就唔好寫成事實

## 七、季節性

- 較強：春節前、端午前、開學前後、中秋前、國慶前
- 較弱：春節後、中秋／國慶備貨結束後
- 季節性只係背景，唔係結論。旺季可以提早見頂。

## 八、Farmio 採購週期

- Cycle A：星期三上午10點前收報價 → 當日回覆 → 星期五送荃灣倉
- Cycle B：星期六上午10–11點收報價 → 當日回覆 → 星期一送荃灣倉
- 決策點係星期三 + 星期六。兩次到貨相隔約 3–4 日。
- 要答：下一個星期三／星期六應該落 輕單／正常單／稍為增加／明顯增加，同埋應該等下一輪報價定而家提前加貨

## 九、Inventory Days Decision Layer

每次必須輸出建議持有幾多日庫存：
- 3–5日：價格明顯向下、跌穿重要支持、需求轉弱、節日備貨後期、供應增加
- 5–7日：橫行、方向唔清楚、接近支持但未確認反彈
- 7–10日：重要支持明確守住、走貨改善、全國同步企穩、需求轉強
- 10–14日：明確突破重要阻力 + 後續升勢 + 季節有利 + 庫存低 + 走貨強 + 供應面配合
- 14–21日：只可喺非常強、非常確定嘅特殊情況
- Farmio 舒適持有約14日，管理層最大可接受約14–21日
- 唔可以純粹因為 Technical 突破就叫 Farmio 持有兩三星期貨

## 十、實際落單量

- 目標庫存數量 = 目標庫存日數 × 最近7個送貨日平均日用量
- 建議落單量 = 目標庫存數量 − 現貨 − 已確認在途貨
- ctx 內冇用量／現貨／在途數據時，唔可以自行估箱數，只輸出庫存日數同公式

## 十一、最終判斷唔可以只靠價格

只有當 Price + Fundamentals + Market Behaviour + Seasonality 大致方向一致，先可以逐步提高庫存。

## 十三、分析哲學

唔係預測明日升定跌。即使唔知道聽日升定跌，都可以令 Farmio 用合理庫存暴露去應對。最終問題永遠係：而家個風險／回報，值唔值得 Farmio 持有更多雞蛋？

## 十四、資料可信度

價格必須核實；市場事實必須有來源；缺數據直接講缺；唔可以自行補值；唔可以因為一個來源就過度下結論；今日冇實質新訊號要明確寫「與上一個Update相比冇重大改變」。
